## 📱 Installation & Sideloading Requirements

### Android (`APK` Package)
* **Minimum OS:** Android 7.0 (Nougat) or higher (64-bit `arm64-v8a` recommended).
* **Co-Existence:** All private server packages use independent package identifiers (e.g., `daniillnull.nulls.brawlstars`) and install alongside the official Supercell client without overwriting existing save data.

### iOS / iPadOS (`iPA` Package)
* **Minimum OS:** iOS 14.0 or later.
* **Supported Sideloaders:** Install the unsigned `.ipa` package via **SideStore**, **AltStore**, **Feather**, **Scarlet**, **ESign**, or **Sideloadly** (PC/Mac).

## 🛠️ Common Troubleshooting Codes

* **"Client and Server Are Out of Sync" / Update Required:** Occurs when the server migrates to a newer client build (such as `v70.648` → `v70.757`). Download the matching APK or iPA build from the [Nulls Brawl Download Page](https://nullsmod.com/nulls-brawl/) and install it directly over your current app.
* **"App Not Installed (Package Conflicts)":** Verify at least `2.5 GB` of free internal storage is available on your device before extracting the 1.2 GB installer payload.
